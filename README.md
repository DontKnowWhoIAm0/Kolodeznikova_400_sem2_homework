# SportBuddy

**SportBuddy** is a web platform designed to help users find training partners for any type of sport. Whether you want to go for a run, play tennis or hit the gym, SportBuddy makes it easy to connect with like-minded people and organize workouts.

## Features

- **User Registration and Authentication** – Secure sign-up and login to access the platform.
- **Workout Request Creation** – Users can create a workout request specifying the city, sport and preferred date or date range.
- **Browse and Respond to Requests** – View a pool of active workout requests and send a response to join.
- **Confirm or Decline Responses** – Request creators can confirm or reject responses from other users.
- **Flexible Scheduling** – Select a single day with a specific time, or a period of multiple days when exact time is not necessary.

## Technology Stack

- **Backend:** Java
- **Templating:** FreeMarker (FTL)
- **Database:** PostgreSQL
- **Frontend:** HTML/CSS/JS

## Usage

1. Register an account and log in.
2. Create a new workout request specifying the sport, city, and desired date(s).
3. Browse other users’ requests and send a response if you want to join.
4. Track your requests and manage responses as a creator.
